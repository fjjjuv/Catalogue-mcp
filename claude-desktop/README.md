# Claude Desktop

Fusionner le contenu de `claude_desktop_config.json` dans votre config :
- Windows : `%APPDATA%\Claude\claude_desktop_config.json`
- macOS : `~/Library/Application Support/Claude/claude_desktop_config.json`

Redémarrer Claude Desktop, puis autoriser la connexion dans
Settings → Connectors (le flux OAuth s'ouvre dans le navigateur).
