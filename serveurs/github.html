GitHub MCP Server officiel

Développement

Le serveur officiel de GitHub (46 outils) : lecture et écriture sur les repos — fichiers, commits, branches, issues, PR, releases, recherche de code.

Typeremote (HTTPS)
Endpoint / commandehttps://api.githubcopilot.com/mcp
AuthentificationOAuth / PAT
CoûtGratuit
Installation⚙️·· (1/3)
Note★★★★★ 5.0/5

Ce qu'il permet

  • Lire/modifier des fichiers sans cloner le repo
  • Créer branches, commits, PR et releases
  • Lire et répondre aux issues et reviews
  • Rechercher du code dans toute l'org

Exemples de demandes

Demande à l'agentRésultat
« Crée un fichier README dans mcp-configs »push_files direct via l'API
« Liste les PR ouvertes et résume les reviews »état du projet en une phrase
« Cherche où la fonction X est utilisée »search_code cross-repo

En quoi il change la vie

L'agent manipule le dépôt distant sans checkout local — commits, PR et releases pilotés en conversation.
