🧩 Model Context Protocol, en pratique

Les MCP sont des serveurs de capacités qu'on branche à un agent IA. Une fois configuré, l'agent peut agir : lire vos boards Trello, pousser sur GitHub, piloter le navigateur, scanner la sécurité de votre code…

Voir les 13 serveurs →

C'est quoi un MCP ?

Le Model Context Protocol est un standard ouvert (Anthropic, 2024) qui permet à un agent IA de dialoguer avec des outils externes via une interface unifiée. Au lieu de coder une intégration par outil et par IA, on configure un serveur MCP une fois — et il marche avec Devin, Cursor, Claude Desktop, VS Code, Codex…

Deux modes de transport : remote (URL HTTPS, souvent OAuth) ou local stdio (une commande comme npx lancée par le client). Notre dépôt fournit un dossier par serveur avec la config adaptée à chaque plateforme.

Pourquoi ça change la vie

  • Zéro copier-coller : l'agent lit/écrit directement dans vos outils (Trello, GitHub…)
  • Vérité terrain : Context7 et DeepWiki injectent la vraie doc — fini les réponses sur des versions obsolètes
  • Sécurité continue : Semgrep scanne pendant que l'agent écrit
  • Actions réelles : Playwright navigue pour de vrai, Computer Use clique sur votre bureau
  • Mémoire : le serveur Memory fait survivre vos préférences entre les sessions
