# VS Code

Copier `mcp.json` dans `.vscode/mcp.json` (workspace) ou ajouter au
profil utilisateur (`MCP: Open User Configuration`).

Note : VS Code utilise la clé `"servers"` (pas `"mcpServers"`) et le
champ `"type": "http"`.

Cliquer sur "Start" au-dessus du serveur dans le fichier, puis suivre le
flux OAuth dans le navigateur.
