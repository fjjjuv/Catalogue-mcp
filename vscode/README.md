# VS Code

Fusionner les entrées de `servers/*.json` sous la clé `"servers"` de
`.vscode/mcp.json` (workspace) ou du profil utilisateur
(`MCP: Open User Configuration`).

Note : VS Code utilise `"servers"` (pas `"mcpServers"`) et
`"type": "http"`. Cliquer sur "Start" au-dessus du serveur, puis suivre
le flux OAuth.
