What is an MCP?

The Model Context Protocol is an open standard (Anthropic, 2024) letting an AI agent talk to external tools through one interface. Instead of one integration per tool per AI, you configure an MCP server once — it works with Devin, Cursor, Claude Desktop, VS Code, Codex…

Two transports: remote (HTTPS URL, often OAuth) or local stdio (a command like npx launched by the client). Our repo ships one folder per server with the config for each platform.

Why it changes the game

  • Zero copy-paste — the agent reads/writes directly in your tools (Trello, GitHub…)
  • Ground truth — Context7 and DeepWiki inject real docs: no more outdated answers
  • Continuous security — Semgrep scans while the agent writes
  • Real actions — Playwright browses for real, Computer Use clicks on your desktop
  • Memory — the Memory server keeps your preferences across sessions
